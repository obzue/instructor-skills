# ARR-SPEC and LYR-SPEC

Minimal templates. Copy into the song folder and fill.

## LYR-SPEC.md

```
# LYR-SPEC
title:
promise:
language:
title_line:
images:
rhyme:
syllables:
chorus_stress:
explicit:
notes:
```

## ARR-SPEC.md

```
# ARR-SPEC
form:
bars:
key:
tempo:
meter:
groove:
chords:
entries:
energy:
vocal:
mix:
picture_spots:
```

Agreement checklist

- [ ] form labels match the lyric tags
- [ ] bar math adds to the target length at this tempo
- [ ] title_line exists inside [Chorus]
- [ ] language matches LYRICS.txt
- [ ] tempo and key match the four-line header
