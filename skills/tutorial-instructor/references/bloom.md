# Bloom taxonomy (2001 revision)

Use Anderson and Krathwohl, not the 1956 noun list. A unit names ONE level as its exit ticket. Lower levels may appear as scaffolding. Do not claim PhD work if the check is only recall.

| Level | The learner can | Exit ticket shape | Typical miss |
| remember | retrieve a fact, term, or step | name it, list it, point at it | blank or swapped label |
| understand | explain in their own words | paraphrase, give the source's example back | parroting the sentence |
| apply | use it on a new case | do the next click, solve a fresh item | knows the word, freezes on the task |
| analyze | break it and relate the parts | what depends on what, what changes if X is removed | summary with no structure |
| evaluate | judge against a stated criterion | which claim is stronger, and why, with evidence | taste without a criterion |
| create | produce something that was not in the source | a new explanation, a critique, a lesson beat | collage of quotes |

## Routing by audience

- First contact with a UI or a book chapter — remember and understand, then one apply
- Operator who must ship — apply is the gate. Remember is a means
- Graduate / PhD seminar — analyze, evaluate, create. Recall is assumed or drilled via spaced review, not the class

## Graph link

Each concept node stores `bloom` as the level required to mark it mastered. A remember-level pass does not master an evaluate node. Say which level the check was.

## Verbs that lie

"Discuss" is not a level. "Understand the importance of" is not a check. Write the observable act.
