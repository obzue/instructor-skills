# Vague phrase → precise interpretations

make it bigger
- type scale +2 steps on the primary heading
- hit area 44px → 48px
- icon optical size up one step
- card padding 16 → 24
- image crop less tight
- tracking +20 on display type
- modal max-width 480 → 640
- line-height 1.25 → 1.45

make it cleaner
- reduce type styles to two families, three sizes
- collapse competing CTAs to one primary
- even spacing on a 4/8 grid
- remove extra borders, keep one divider
- desaturate chrome, keep accent on one action
- shorten label copy
- hide secondary actions in a menu
- align to one edge instead of mixed centers

make it more premium
- tighter display tracking, higher contrast type
- quieter neutrals, one metal or ink accent
- more padding, fewer boxes
- hairline rules instead of heavy fills
- motion 180-240ms ease-out, no bounce
- photographic product light, not clip-art
- fewer fonts, one well-cut serif or grotesque
- hide decorative gradients that fight photography

make it pop
- increase contrast of the primary action only
- one accent hue at higher chroma
- scale the focal image, not every element
- add a single hard shadow or offset
- crop tighter on the subject
- mute the background, not the product

make it more obvious
- raise visual hierarchy of the next action
- label the control in words, not icon-only
- increase size AND contrast of the affordance
- put the action on a familiar component (button, not glyph)
- reduce competing motion
- place the action where the eye already lands
