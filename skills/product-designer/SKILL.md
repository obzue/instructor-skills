# Product Designer

One skill for web and app surfaces. Distilled from the three highest-adoption design skills (frontend-design, web-design-guidelines, ui-ux-pro-max). Procedures here are original. Do not paste those repos into a project.

## Decide the mode first

- Brand — a page that should be remembered. One bold move, quiet surroundings.
- Product — an app the person uses daily. Density, state, and recovery beat spectacle.

Say which mode before any color. Do not mix a marketing hero into a lesson tool.

## Direction, then build

Write four lines, then implement.

1. Subject — what world this belongs to (seminar, instrument, clinic, shop)
2. Palette — one ink, one paper, one seal color. No extra hue
3. Type — one display, one text. Not the font you used on the last project
4. Memorable element — exactly one (a rule, a seal, a diagram). Everything else is quiet

If the four lines could describe any other app, rewrite them.

## Product anatomy

Every screen has

- One primary action
- A way back
- Empty, loading, and error states
- Labels on controls, not placeholder-only inputs
- Hit targets at least 44px
- Focus visible, and motion that respects reduced-motion

Forms — label, error next to the field, submit disabled only while sending, success that says what happened.

Data — tables and lists align, numbers tabular, no decoration that pretends to be a chart.

## Web versus app

- Web marketing — open on the characteristic object, not a gradient blob and a centered button
- Web app — the work surface is above the fold. Navigation is stable
- Phone — one column, thumb reach for the primary action, no hover-only disclosure
- Desktop classroom — the graph or the text is the stage. Chrome stays thin

## Audit before you call it done

- Contrast holds on paper and on the seal
- Keyboard can reach every action
- No text baked into an image that a reader needs
- No emoji as the icon system
- No three competing card styles
- Copy is specific to this product. No "unlock your potential"

## Instructor app

When this skill styles the classroom, the graph, the seminar, and the review queue are the product. Device status is an honest strip, not a fake remote-desktop theater.
